# 发车灭→亮→灭时序

现场顺序：小朋友在灭灯状态摆车、框灯、ARM并示意ready后停止操作；裁判亮灯，几秒后自动熄灯，车辆此时才获得出发许可。

ESP32 0.4.12先记住本轮初始灭灯视野，等待同一灯面经背景曝光补偿后持续变亮。稳定ON至少4帧且300ms才冻结灯面与亮灯基准，随后仍需3帧且400ms的熄灯证据。许可确认后锁存到STOP或最终停车；初始OFF、变亮、短闪光、旧会话均不直接放行。STOP重来或确认前断帧后清除旧周期证据。

此前0.4.11手动范围可能把初始灰板当成ON基准，导致实际亮灯后的OFF不被识别。现在用显式时序门控解决，不以固定黑色阈值代替灯周期。
