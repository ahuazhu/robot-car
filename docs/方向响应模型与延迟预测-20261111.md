# 方向响应模型与延迟预测 — v0.6.112

## 证据与修复范围

独立实际PWM测试绕过DWPP：90/70右转几何测量7.13–7.37°，70/90左转14.04°，80/80直行左偏0.34°。视觉中段右转约0.067–0.081rad/s、左转约0.122–0.151rad/s，前进投影约0.146–0.152m/s。原程序把PWM比例直接当轮速比例，用同一名义杠杆解释左右转；它既影响输出，也影响缺测时的运动预测。测试支持在当前工况采用方向响应模型，但不能证明此前闭环摇摆仅由这个因素导致。

## 实现

新增纯计算模块`robot/control/drive_response.py`：曲率与努力比例双向换算；DWPP凸可行域使用左右不同的有效杠杆，选择结果和PWM换算遵循同一模型。左右方向由实际选择的角速度决定，不由期望目标方向决定，因此反向制动过渡也保持一致。制动后实际弧线检查、任务零速和STOP不绕过。

当前配置左曲率增益1.15、右0.60，含义是相对于原名义ratio/0.15模型的地面光流坐标曲率，不是直接把轮PWM乘这两个数，也不是给光流读数乘比例。参考低档视觉累计曲率约左0.97/m、右0.47–0.51/m，对照PWM比例0.125对应名义0.833/m，取粗略值而非过拟合小数。右转44.4cm平移异常样本不用于物理平移标定；全部原始数据保留。

命令到首次采样回执约0.108–0.133秒，加入0.12秒的**待实测验证**命令延迟估计，沿用原0.4秒响应时间。回执延迟含采样，不能当作纯机械时间常数。规划时从画面时间按已发送指令历史预测到新指令预计到达时刻；未发送的方案不进入历史，重复计算不推进预测；STOP、未知搜索指令、失效方案撤销历史。只用于规划控制状态，原始视觉速度和道路/横道里程不改写。无新角速度积分、无自动在线学习。

缺测前馈额外限制外侧峰值，避免只约束平均PWM却在大转向时超出低置信努力上限。新`motor_max_pwm`在最终串口输出和展示共用的补偿函数处按同一比例限幅，巡线/搜索均受约束；默认硬件能力仍255，本试验配置90。

## 验证配置与边界

当前0.15m/s规划上限、实际PWM≤90、高置信增益1.0，保持已通过数值回归的其他速度和任务规则；不更新UNO或ESP32。标定仅覆盖平均PWM80附近、2秒起停及木地板，强曲率/低内轮PWM/不同材料的响应仍属外推。限速是控制验证范围，不是新的最快圈速参数。需先验证直线接单弯，观察摆动、出弯回正及压线，再决定扩大范围。

新增测试检查方向双向换算、非对称可行域、实际线端输出、STOP与未知指令撤销历史、命令到达顺序与处理年龄，以及不同采样周期下独立延迟/不对称一阶仿真。仿真不是实车结论。历史回放174个可评估快照，DWPP选中151次；任务占用阶段排除，历史姿态不会随新输出改变，因此不能从回放推算圈速或宣称摆动消除。

完整回归与部署结果待本轮实际执行后补充。控制台安装后保持STOP、未ARM；第一次场地测试待部署核验后由用户启动。

## v0.6.113：有效但低分辨率测速的控制切换修复

本轮原始数据保存在 `.maixpy/v112-field-review/`（状态、照片、设备日志、83条行驶CONTROL快照）。其中78条运动测量有效，32条却进入了无速度反馈分支；这些是事件采样计数，不代表时间占比。frame503输出90/86，frame507降至6/6，frame511开始重新加速；frame515输出79/85，frame519又降至8/8。frame507前进速度0.0534m/s、两倍位移误差折算速度0.1106m/s；程序把“不能从单帧确认非零位移”当作测速失效，强制0.0375m/s备用上限，再用备用前馈压低努力。停稳后误差更小、满足静止条件，恢复反馈积分并再次加速。这是明确的模式切换缺陷，并非DWPP必然如此。

修正：有效运动量始终保留同一个速度反馈入口，传入2sigma/dt误差区间。目标在区间内时保持已有积分努力，超过上下界才对可确认的速度误差调节；区间下界确认超速时仍制动。真正无效的光流、长控制间隔保留原有界降级；横道/STOP硬零和曲率/外轮限幅不绕过。原始光流、中线与里程不改动，不加大左右转补偿，不新增转向积分。

右转内侧压线的全部原因尚未证实：frame545线端90/47，后续实测右转明显；frame653期望曲率约-0.025/m（近直行）但动态窗口仍在旧方向制动，输出14/0。低内轮PWM已超出90/70标定范围，PWM比并非轮速比。修复模式切换不等于证明上述强曲率电机模型准确。本轮保持0.15m/s、PWM90、左右增益与延迟参数不变，只验证确定的切换缺陷，避免同时改动多个假设。

新增回归覆盖本轮有效但位移未超过误差的测量、误差区间内无积分累积、确证超速减速、任务零输出以及真正失效的降级。离线测试不能证明实车摆动消失，部署后仍需要用户按START复测直线与一个右弯。
