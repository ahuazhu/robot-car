# 完赛优先停车审查与横道恢复（v0.6.96）

用户明确：宁愿压路沿、越过横道线或损失任务分，也不应因信心不足永久停住。v0.6.92–0.6.94只把此策略应用于巡线/寻路层，横道任务仍可以无限否决电机输出，属于策略覆盖遗漏。

## 本次卡死证据

Maix v0.6.94帧4199：道路连续观测已326帧，置信度约81%，车身检查有余量，UNO持续确认零速且无通信错误。最终输出为零的原因是`CROSSWALK RECOVERY_HOLD`，不是道路没有拟合出来。

启动后约18.6秒，横道停距估计约33.7cm，位置误差约2.5cm。接着数帧光流失败，横道按最大可能运动扩张位置区间：约19.1秒误差已38.9cm，约19.7秒变成54.2cm。程序因此无法排除已经压线，在停距估计仍约31cm时进入STOPPING/RECOVERY_HOLD。后续画面只剩两条可用条纹，无法按已有三条纹模板重新定位；三条纹门槛之外，原关联半径6.5cm也不足以校正当前约7cm的偏差。

实际截图与日志已冻结在`.maixpy/stuck-repeat-20261111/`，最小停车状态在`tests/fixtures/crosswalk_unverified_20261111.json`。54cm是算法累计的不确定范围，不是小车实际移动了54cm。此前修复覆盖了年龄阈值和三条纹定位，却没有覆盖“运动连续失败、部分条纹不足、横道恢复状态永久零输出”的组合，也没有把完赛优先落实到横道的最终输出权限。

## 统一后的行为

已有`road_search.finish_priority=true`同时传给巡线与横道任务，无需另开一套现场开关。

位置/运动置信度不足只影响恢复速度，不能单独获得停车权限。v0.6.95曾增加4.8秒验证等待，用户指出等待不能改善同一画面的信息；v0.6.96移除该等待和对应时钟。

- 横道位置区间过宽、未知或已越线，测速缺失、无道路目标、接近调节器算出零输出：立即进入`RECOVERY_PASSING`，有可用道路就低速跟线，没有道路就交给主动寻路。不要求先停稳或先收到零速回执；真实通信故障仍由电机监督层停车。
- 当前距离区间完整且窄于整个20cm合法停位窗口，按制动条件发起正常停车：保留同一次3.2秒礼让，完整停位/红灯/视觉停稳证明才标记合法PASSING。证明始终不全时，以收到零速回执起算的同一3.2秒为未验证退出界限，恢复低速；回执短暂缺口不重新计时，退出当帧仍需零速回执。通信故障仍终止任务。完成这次停留后，同一横道不会再要求第二轮礼让。

恢复阶段逻辑PWM峰值限60，保持左右轮比例，车身/历史预算、短转向租约及通信看门狗继续适用；不启用高速规划。`yield_verified=false`、`yield_completed=false`明确保留，界面显示“停位未验证，低速继续”，不把有风险的通行伪报为合法礼让。重新看到可信横道位置且仍有接近距离、也尚未执行完整一次礼让时，可恢复正常APPROACH。

## 相似场景审查

| 场景 | 原来的零速原因 | 本次处理 |
| --- | --- | --- |
| 横道位置区间过宽、可能压线或停位不明 | RECOVERY_HOLD永久否决所有跟踪及寻路 | 当帧进入未验证低速恢复，不先停车 |
| 横道APPROACH中测速缺失、位置缺失或无跟踪指令 | 接近阶段反复输出零，没有经过停留阶段也没有恢复出口 | 当帧交回低速跟线/主动寻路，不设等待时钟 |
| 红灯/停稳证明始终不足 | 验证条件永远不成立，物理停留计时无法完成 | 明确位置发起的礼让只执行同一次3.2秒；证明不足则未验证继续，不重复停车 |
| 地图寻路启动前，光流始终声称还在动 | 尚未启动搜索预算就一直SETTLING | 完赛优先切入有租约的视觉探路 |
| 视觉探路之间，噪声使光流始终达不到停稳阈值 | 每轮仍会超时重试，但每轮都只发零输出 | 新鲜零速回执、已发零指令经过0.75秒响应/看门狗等待后允许0.12秒短转向；标记ZERO_ACK_FALLBACK，不冒充视觉停稳 |
| 没有道路或预测到期 | 需要恢复道路证据 | 维持多轮有限探路；有可用历史指令时低速接续 |
| 视觉处理持续超过280ms | 当前控制数据不及时 | 保留零速，及时帧恢复后可继续；本次卡死时处理约174ms，不是此原因 |
| STOP/退出、完赛、真实通信故障、配置/接口异常 | 明确结束任务或不能可靠控制硬件 | 保留解除驱动，不自动重启任务 |
| 未ARM、等待真实发车信号 | 尚无启动授权 | 保留等待，不因超时自行抢跑 |

没有通过取消合法礼让证明来假装修复评分逻辑；普通验证路径保持，增加的是用户明确选择的未验证继续策略。此策略可能失去横道任务分或压线扣分，符合本次完赛优先要求。
