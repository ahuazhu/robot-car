# 固定场地的路面识别与预测评估

评估日期：2026-11-04。待部署源码：v0.6.58；本次只读检查到的设备仍运行v0.6.56，镜头对着桌面，未使用它评估赛道识别率。没有重启设备或发送驾驶指令。

## 场地约束与处理边界

场地外部为绿色，路面为灰色，左右路沿及发车线、斑马线均为白色。白色像素本身不能区分路沿和横纹；边界仍需由道路侧、绿色外侧、方向与宽度共同确认。单侧可见时允许使用有几何证据的单边道路，不要求每帧同时看全两侧。

现有实现已经使用灰/白/绿法向探针，而非简单追踪白色像素。本次保留原始亮度及局部对比度两个通道：反光/阴影样本依赖对比度通道，弱边界样本依赖原始亮度通道，不能只留其中一个。

## 已落地的两项优化

1. **绿色不再兼任灰色路面。** 普通亮度分支原来存在低饱和度浅绿与灰路面的重叠，归一化分支则已经排除了绿色。现在两条分支一致。一个独立合成反例只有绿色场地和淡色反光条、没有道路；旧实现误识别为单边路，修复后左右镜像均拒绝。
2. **当前场地可以反证旧预测。** 感知层提供每帧共享的 `RoadSurfaceEvidence`。只有可见、高饱和度的明确绿色，在避开投影误差和网格余量后仍形成至少7.5cm连续段，才撤销旧道路假设。白横纹、灰路面、黑色遮挡、颜色重叠及不可见区域均不构成反证，也不刷新历史。导航撤销整条受反证的旧模型，避免跳过绿色断口选远端道路；寻路地图及旧边界轨迹同步撤销受反证的依据。同帧新的真实观测仍可建立新路。

历史支持仍保留原来的0.6秒、5cm盲行及误差界限。反证只提前撤销已被当前画面否定的假设，不延长预测。正常灰路/白线样本直接跳过距离变换，减少新增计算。

117张中仅 `weak-fragment.jpg` 的几何发生变化：保持双边和第3个亮度分支，内部置信分数从0.941294升至0.947817，13个路径点变为14个，双向点到折线最大差约1.97mm。这是两版差异，不是相对真实中心线的误差。

连续85帧的路径、置信度、状态和指令提案逐帧相同。845及855帧仍各有一个待确认步骤，没有新增中断。该序列没有触发新的绿色反证，因此它证明回归保持；反证能力由独立反例测试验证，不能据此宣称实车错误预测率已下降。

错误预测反例保留真实 `seven_bars.png` 不变，只将旧历史道路横移25cm并模拟本帧没有新测量；它用于隔离策略缺口，不代表实车曾经这样行驶。横纹、变暗图及未知区域对照仍保留历史原时效，没有被错误清除。

主机计时采用每静态图2轮热身、7轮采样，连续序列1轮热身、5轮采样。独立测量中位约1.984→2.009ms，完整追踪中位约8.435→8.722ms。新增开销约0.29ms；顺序运行仍有主机波动，不能代替MaixCAM2耗时或实车圈速。

## 验证与剩余薄弱点

原生路径574项回归全部通过；Python回退路径555项通过、19项原生专用测试跳过。新测试见 `tests/test_surface_topology.py` 与 `tests/test_surface_prediction.py`，覆盖无道路反光反例、白横纹保留、未知不刷新历史、绿色断口不跳跃、运动及坐标原点、旧地图撤销和同帧新观测接管。

密集横纹与两侧白边完全连在一起时仍有薄弱点。在7根横纹的合成压力矩阵中，现有轮廓会在交汇处产生短而弯折的伪边线；当前真实横道样本未复现该完全失效。可靠的后续方向是连续绿白外包络与实际白边厚度联合估计，不能直接放宽长度、曲率或车身检查。本次没有把该研究原型接入驾驶。
