# 停车策略与横道停留修复 2026年11月7日

本次源码版本为Maix v0.6.73。按用户最新确认：完赛越过最后一次计圈白线后继续正常巡线40cm，直接停车，删除原5秒要求；横道以车身最近点约10–15cm为制动目标，不做低速精细对位，视觉确认停稳、零输出回执和红灯连续满足3.2秒后交还正常巡线。路况、通信和STOP保护仍优先。

## 原始规则

已读取项目原始《附件1：2026年上海市青少年机器人知识与实践比赛规则.docx》“自选项目6 视觉竞速”四.1(3)：整车垂直投影不压横道，最近距离小于20cm，停留并亮红灯超过3秒。规则并不要求某一个精确厘米位置。3.2秒为本项目执行余量，计时起点是物理停稳而非发送零命令。四.3(5)另有原地无明显位移超过5秒中止条件。

白线40cm属于现场调试要求；它不等于程序已经识别龙门横梁并验证完全越过横梁，且未替代规则的龙门停车验收。

## 横道长停的证据和根因

部署前v0.6.72日志中，frame48353–48443从STOPPING至PASSING约15.08秒，车身最近距离已在约11.5cm至10.3cm；多次HOLD与STOPPING之间来回切换。另一事件frame40566–40635从STOPPING至PASSING约11.12秒，停在约24cm，始终未能验证合法停车位置。

代码存在三处叠加：固定6cm/s接近上限和仅积分的速度反馈使接近很慢；速度参考下降后旧扭矩没有同步下降，容易触发20cm外的提前停车；位置验证失败后先等待确认截止时间，再从零开始3.3秒RECOVERY_HOLD；逐帧光流速度/角速度阈值又把小位移抖动当作重新移动，反复清空停留。最新日志一次长停的58条控制样本中，有4条光流无效，另外多条瞬时速度超过旧停稳阈值。无效运动仍不能用零命令假装实测停稳。

## 新执行方式

横道使用随距离变化的制动速度边界，包含命令延迟和速度反馈响应时间；取消固定龟速上限。速度参考下降时同步降低已有调节输出，保留双轮比例，减少提前刹停与反复接近。正常15cm附近触发停车，2cm作为独立防压线制动底线；速度过高或证据不足时允许更早保护停车。合法范围内不挪动对位。

位置证明、停稳证明和礼让时间分开维护，共用同一段连续物理停留。位置未证实的异常流程不再加一次完整停留，也不会显示为合法任务成功。短窗根据实际运动变换的位移趋势判断微小抖动，持续缓慢移动不能靠抖动过滤计成停稳。明显运动、缺失运动测量、长视觉间隔及回执/红灯丢失仍会中断连续停留。

完赛用地面运动变换积分车身参考点的前向行程；相机因原地转动产生的圆弧位移不计入，倒车抵消已有进度，误差进入保守行程下界。计数越线帧只建立基准，不追补跨线前移动。达到40cm后由既有最终STOP路径归零、锁定结束并清除发车许可。道路/横道对运动的限制仍在；没有定时盲行或PWM换算米数。实际滑行使停车点可能超过40cm，不追求精准对位。

## 右侧看得到路却停住

停住原图中近处右下道路和远处左上道路被绿色隔带分开。旧代码把它们的边沿配成一条道路，两边拟合互相否决，最终报EDGES DISAGREE；四次短脉冲探路已经耗尽。

新逻辑仅在正常双边匹配失败时验证连通路面身份。灰路和白漆同属可通行组件，白色横纹不会切断组件；两边必须分别有足够内侧像素支持、属于不同组件、近路在误差范围内唯一更近，且中间有足够长的明确绿色。随后采用该路原有单边推算中线，仍通过车身检查。没有绿色证明、近远距离相当或中线落入绿地时仍拒绝。

停住原图离线回放由LOST恢复为ONE LEFT，能够生成右转指令；测得隔带约24.5cm，所选轨迹车身检查通过。真实图、镜像及缺少分离证据反例已纳入回归。这不能代替重新跑过该弯的实车验证。
