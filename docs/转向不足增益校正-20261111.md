# 外侧压线与统一转向增益（v0.6.101）

用户实测v0.6.100后仍反馈转向稍有不足、压弯道外侧。该版补齐了车身风险绝对限速，但沿用了0.85的转向增益。最新抓取时已完成圈数并停车，没有发送控制命令；原始数据在本机`.maixpy/understeer-20261111/`。

307份运行状态中，已发布的轮速转向比例与请求比例基本一致，没有看到两侧轮速被分别裁剪而丢失转向的证据；同时存在实际转向延迟，转向自学习在该批样本中未满足稳态条件。稀疏视觉运动估计不能作为新的底盘标定。

本轮只调整既有统一参数`steering_gain: 0.85 → 0.95`，对同一几何目标的请求曲率提高约11.8%。纯追踪、基线轮速和车身预测使用同一个参数；不增加单独左弯/右弯补丁或运行时模式。直道目标的横向误差为零时，改变增益不改变轮速。曲率、车身余量及置信度仍共同限制行驶速度；最高速度、峰值、任务和控制租约沿用原配置。

`test_understeer_gain`验证左右弯同一增益在巡线指令和车身预测中的效果、镜像对称、直道输出一致、真实峰值约束及参考速度仍受包络限制。历史左右弯限速测试同时纠正制动计算依据，见前版[统计更正](车身风险限速遗漏修复-20261111.md)。配置和数值测试不保证实际转向提高同等百分比，外侧压线和出弯是否出现内侧修正过大仍需同赛段观察。
