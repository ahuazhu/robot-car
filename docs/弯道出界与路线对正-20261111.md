# 中线置信度参与统一速度规划（v0.6.99）

## 现场证据

v0.6.98在右弯后仍沿旧中线行驶。帧2033中，旧路线约41cm连续落在明确绿色上，原输出仍为补偿后的[97,95]；当前候选与旧预测也明显不一致。旧策略仅降低诊断置信度，却把恢复轮速归一化到固定档，置信度没有真正约束执行速度。

前一轮帧576约167ms处理完成，接受新模型后立即没有前向追踪点；随后快照中的候选道路距车约88cm，超出65cm控制范围。这是路线接纳问题，不能归因于慢帧。

## 统一模型

主中线持续保存，经运动补偿后由被接受的新观测修正。没有按时间、盲行距离或误差阈值删除模型的逻辑；观测时间、误差及当前是否看见仍如实记录。低置信度控制速度，不清空几何。

`core.route_confidence`集中计算置信度及其速度比例。当前逐点置信度综合原观测质量、定位误差、新旧中线的位置与方向差异，以及可见路面反证；速度控制还计入路径支持长度。位置和方向差异越大、定位误差越大、旧路线落在绿色上的长度越长，置信度越低。缺帧不会清掉已发现的分歧；接受可信的新观测后恢复相应证据。

统一速度规划取以下限制的最小值：最高速度、中线置信度、弯道侧向加速度、外侧轮速度，以及前方可用路径末端的制动距离。随后沿用前后向加减速规划和实测速率反馈。置信度不再通过固定“分歧30档”“绿色就旋转”等分支控制轮速。

当前置信度速度上限为：`最高速度 × max(0.1, min(1, 置信度 / 0.8))`。最高速度0.30m/s时，置信度0.8以上允许0.30m/s、0.4允许0.15m/s、0.08及以下保留0.03m/s慢行参考；曲率和制动仍可进一步降低。此比例是待实车调节的工程参数，不是对实际车速的保证。只有置信度降低不会单独请求零速。

缺少可靠测速或正常速度控制暂不能接管时，旧控制器产生的轮速幅值也受同一个置信度比例约束；不再额外乘旧质量平方根，也不再由寻路器重复压到固定恢复档。实测静止可使用速度反馈逐步建立驱动力。低档能否克服当前电机死区仍需实车验证。

## 几何与任务边界

- 新候选必须在当前前向控制范围内才可覆盖既有主路线；持续确认一个远处侧向道路不能证明它就是要跟随的路线。
- 车身与附近主路线大角度错向时，使用通用航向对正：70度进入、20度退出；旋转逻辑峰值60、租约0.15秒。这是几何控制动作，与颜色或固定低置信度分支无关。
- 横道和计圈使用被主模型接受的路线，不使用未被接纳的候选道路。
- 预测路径不外推到已测几何之外；前方曲线耗尽交给主动寻路。
- 每次历史跟随命令仍需及时的新控制帧续签，最长0.25秒。电机命令时效与主中线寿命分开。
- STOP、完赛、正常横道3.2秒礼让和通信保护仍优先。基础/稳定档135/155、加速斜坡400PWM/s、实际输出峰值200及最高速度0.30m/s保持。
