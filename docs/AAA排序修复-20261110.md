# AAA 启动器排序修复

## 原因与修复

Maix 的 `/maixapp/apps/gen_app_info.py` 先输出优先应用，再按应用 ID 排序；`AAA` 只是显示名，真实 ID 是 `robot_curve_follow`。每次部署重新生成 `app.info` 后，AAA 会回到靠后的位置。本次修复前实机 SDK 列表中排第29。

安装器现在将 `robot_curve_follow` 设为生成器的首个优先项，保留应用 ID、其它优先项及其它应用的相对顺序。通过解析 Python 语法树只修改优先列表，备份原文并原子替换；遇到不支持的生成器格式则停止安装。重复安装不会重复添加，安装失败时同时恢复生成器和应用列表。系统升级若覆盖该 SDK 文件，需要重新运行新版安装器。

## 验证与设备状态

- 12项构建及安装测试通过，包括独立重新生成列表、重复安装、保留其它应用及失败回滚；驾驶安装包构建通过。
- 2026-11-10 已原地更新 Maix 的启动器元数据，未重新安装或重启当前小车应用。
- 实机独立重新生成列表后，SDK 返回前五项为 AAA、App Store、Settings、Benchmark、Camera；47个应用的全部注册字段保持一致。
- 小车进程、标定、运行配置和发车配对配置保持不变。此次没有发送 ARM、STOP 或驾驶指令。

修复前的生成器与应用列表均在设备上保留 `.before-robot-first-*.bak` 备份；本机原文、执行脚本及核验结果存于忽略目录 `.maixpy/launcher-order-20261110/`。返回设备桌面时会读取新顺序；本次没有进行屏幕截图验收。
