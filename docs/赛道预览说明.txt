赛道预览：只识别画面，不控制电机

1. UNO 保留 uno/uno_uart_test/uno_uart_test.ino，不需要重新上传。
   这个固件保持电机停止。车底电池开关保持关闭，电脑 USB 给 UNO 供电。
2. MaixCAM2 用电脑 USB 供电并开机，独立摄像头电池保持断开。
3. MaixVision 连接 MaixCAM2，停止之前运行的程序。
4. 打开 maixcam2/lane_preview/main.py，点击左侧靠下的单三角形“运行当前文件”。
   不要在电脑 Python 中直接运行。
5. 将小车放在赛道中央，镜头正对车头方向并略向下。
   下半幅应该能看到两侧绿色区域及完整道路，上半幅尽量兼顾路牌。
   若道路占满整个画面，程序不会猜测被裁掉的边界，需要调整视角。
6. 画面标记：
   绿色点：灰/白道路与绿色场外区域的交界，靠近白色边线外侧。
   黄色点：每条扫描横线上的道路中心。
   青色竖线：画面中央，用来和黄色点比较。
   红色问号：该行没有可靠的成对边界。
   ROAD OK：当前有至少三组候选边界，且包含近处道路。
   ROAD UNCERTAIN：证据不足，不能据此驾驶。
   offset：近处道路中心相对画面中心的像素偏移，正值在右，负值在左。
   ROAD OK 是启发式检查结果，不代表识别一定正确，仍需目视检查落点。
7. 手动移动小车观察：直道、弯道、横向停止线附近各观察一次。
   黄色点应落在灰色道路中间，绿色点应沿道路两边，停止线不应使中心大幅跳变。
8. 保存一张实际车载视角的 MaixVision 运行截图，用于调整阈值和视角。

本程序不会打开串口，不发送任何行驶指令；它尚不识别“停”和“5”路牌。
第一版针对灰/白道路、绿色场外；严重反光、褶皱和绿色遮挡会造成误检或漏检。
应先拉平地布，再按实际镜头画面调整 main.py 顶部 HSV 阈值和扫描位置。
电脑照片上的离线检查不能代替 MaixCAM2 实机验证。

离线测试（仅开发验证，需要 numpy、opencv-python-headless）：
python3 tests/test_lane_preview.py maixcam2/lane_preview/main.py

图像转换 API 依据：
