使用注意：
- Codex 与 MaixVision 共用同一设备的摄像头、屏幕。由 Codex 运行前，先停止 MaixVision 当前脚本。
- run 会进入开发模式并中断设备启动器应用。
- 正常程序应使用 app.need_exit()，也可提供有限运行时长以正常结束；不要依靠超时强杀释放硬件。
- 调试取图仅在程序实现调试图片保存且带 --debug-images 时启用。
- 每次运行记录在 .maixpy/runs/<运行编号>/：summary.json、stdout.log、stderr.log、artifacts/。
- run 命令返回成功不代表应用成功；检查 summary.json 的 exit_code 和实际日志。
- 测试完用 mode exit 恢复设备启动器。
- UNO 程序和已验证接线没有修改；安装验收程序不发送电机控制命令。
