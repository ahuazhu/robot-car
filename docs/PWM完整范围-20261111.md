# v0.6.106：解除PWM200限制

按用户要求，UNO接收范围、Maix输出补偿/回执校验和ACTIVE调速器力度上限统一为完整PWM范围。

| 项目 | 调整前源码 | 当前源码 |
| --- | --- | --- |
| UNO左右轮指令范围 | -200～200 | -255～255 |
| Maix最终输出范围 | -200～200 | -255～255 |
| ACTIVE最大逻辑力度（补偿前） | 163 | 218 |
| 最大参考速度 | 0.30m/s | 0.30m/s |

ACTIVE力度从共享`MAX_MOTOR_PWM`计算，不再保留另一个写死的200。最终输出按共同倍率饱和，
保留左右轮比例；255以上及-255以下指令和回执仍拒绝。350ms看门狗、STOP、发车许可、
低置信度速度包络及车身风险限速保留。巡航档位、标定、runtime未改；旧163逻辑直行指令
仍输出200，调速器存在速度误差时可以使用新增力度空间。力度归一化也会随新上限变化，
不能将其理解成所有低于200的调速输出都完全不变，或车速必然提高27.5%。

本轮USB读到UNO启动信息已经是`maxPWM=255`。使用新源码编译的10740字节固件，与板上
flash逐字节校验一致，所以没有重复写入UNO。实际需要部署的是仍限制200的Maix端。
USB检查只读取日志和固件，未发送ARM或运动指令。

验证覆盖201/250/255双向指令、±256越界拒绝、补偿比例、ACTIVE超过200且维持物理速度上限、
STOP和通信看门狗。固件离线C++检查及UNO编译通过；板上固件校验记录
`.maixpy/pwm255-20261111/uno-verify.log`。
