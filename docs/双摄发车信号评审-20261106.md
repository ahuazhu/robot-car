# 双摄发车信号评审（更新于2026-11-07）

ESP32 固件0.4.2-self-recovery、Maix应用0.6.64。ESP32上仰识灯，Maix下视巡线，UNO执行电机及刹车指令。本次不改变电机接线或刷写UNO。

## 规则依据

用户提供的《附件1：2026年上海市青少年机器人知识与实践比赛规则.docx》“自选项目6：视觉竞速”：灯面6cm方形、中心离地35cm；灯色和亮度现场确定；先亮灯等待，熄灯后5秒内小车垂直投影须完全越过出发线。不能把“任意亮度变化”当成发车。规则允许闪光干扰、尺寸及角度误差，且禁止外部有线／无线控制或数据。

公开的[2026徐汇区规则](https://www.wflms.cn/oss/3b/3bb3e3be-079d-4c43-9995-d4a5b1c0263f/3bb3e3be-079d-4c43-9995-d4a5b1c0263f.htm)可交叉核对相同视觉竞速条款，但不能替代市赛最终通知。当前两板之间Wi-Fi是否被现场认定为外部通信，应以裁判解释为准；当前版本未完成有线发车许可。

## 本次实现

- 青色定位框由64×32扩大至96×84，原图坐标`[112,22,96,84]`，中心仍为`(160,64)`。只改大小，不移动中心。
- 先在大框内寻找紧凑亮区域；多亮度层分离泛光与背景，合并同一灯面的嵌套候选。拒绝出框、过细长、稀疏及相近强度的多目标。当前是亮区域形状筛选，并非完整四角或灯具身份识别。
- 手动ARM后，以至少4帧、300ms确认位置和亮度稳定，显示黄色灯面框；之后固定检测这块灯面，不追逐新亮点。
- RGB565区域下采样、轻微高斯滤波和Lab亮度查表。周围背景环用于补偿轻微公共亮度变化；明显曝光变化（背景亮度差超过12）或结构残差超过14时进入不确定，清空熄灯计数。
- 灯面背景对比下降门槛取`max(10, 4×基线波动, 12%基线对比)`，且至少70%灯面像素变暗10；连续至少4帧并持续600ms才确认。变亮不触发，允许熄灯后仍有环境亮度。
- 大范围光照永久变化、目标被遮挡或未完整入框时需要摆正并重新ARM。持续遮挡如果在视觉上与真正熄灯完全相同，仅靠亮度仍无法保证区分。

借鉴的是成熟的[ROI亮区域与形状筛选](https://docs.openmv.io/v5.0.1/openmvcam/tutorial/image/finding/blobs.html)、背景参照和时序状态机；未引入神经网络。GC2145当前官方驱动的自动曝光／增益控制部分为占位实现，不能照搬OV2640的曝光锁定调用。本版本不声称已锁定曝光。

## 协调与许可

Maix是唯一驾驶决策方，ESP32仅提供本轮发车许可。当前两板之间使用局域网HTTP；81端口为独立发车服务，80端口为预览与公开状态，避免图像发送占用发车服务队列；电脑和浏览器不参与识别和许可判断。网络请求位于独立线程，巡线循环不等待网络。

配对密钥经USB首次写入，保存在ESP32 NVS与Maix权限600的私有文件，不打包、不提交、不输出日志。每次ARM使用新的128位会话并绑定ESP32启动编号；重复ARM不重置同一会话的基准。协议2明确要求DARKER和有效锁定灯面，旧协议拒收。

ESP32心跳租约2秒。Maix只接受帧龄不超过400ms、接收不超过750ms、持续推进的帧；重启、帧倒退、过期、断线和会话不符都要求重新ARM。首次候选熄灯起超过2秒的事件不能因道路稍后就绪而突然发车。UNO ARM前再检查一次并单次消费；STOP同步清除本地会话，迟到结果不能复活它。行驶后结束灯光检测，ESP32后续断线不打断已经开始的巡线。

用户提出的下一步结构可实现为“Maix准备驾驶指令，UNO在有效ESP32许可到达前强制零输出”。需要在现有白色I2C线或其他机内有线链路上实现带本轮编号的许可；默认禁止、断线不放行、STOP清除、发车后一次性锁存。厂商确认白色口用于I2C通信，但当前尚未核实本板外部插座的GPIO及完成端到端协议，不能把现有白线当作已经可用的发车通道。Type-C接口形状不能证明USB主机能力。

## 历史回测与局限

运行`esp32s3/video_preview/replay.py --output .maixpy/esp32-rule-start-20261107/replay.json`，直接编译固件使用的C++检测内核。16张历史开／关灯画面、17张路人／抖动画面来自旧Maix相机；按320×240原图回放，并另报告整张画面整数平移至新框的情况，不做局部灯面贴图。填充的未知区域不能成为有效灯面或背景证据。

原构图的灯未完整落入新框，均不锁定；全图对齐后，小灯亮→灭4帧、630ms确认，反向不触发。大灯可以形成候选，但因原始上下文不足及关灯时背景结构变化，未能确认；保留这一未通过结果。17张未切灯序列无误触发。样本无原始时间戳，回放时间为指定测试间隔，不能作为实机延迟测量。

合成及协议回归覆盖短闪、亮度增益变化、移动目标、框外变化、新亮点、背景结构变化、残余灯光、计数／时长双门槛、计时回绕、旧协议、非法目标框、过期和重复消费。仍需最终ESP32安装角度与真实灯面完成不驱动车轮的亮→灭实测，不能用历史样本宣布现场准确率。
