# 持续中线与单边恢复（v0.6.98）

用户要求：维护一条持续预测的中线，逐帧运动补偿，确认的新观测修正预测；没有更可靠的新路之前，不因时间、行驶距离或误差阈值淘汰旧中线。低信心进入低速恢复，不停着等信心变好。同时再次提高正常路段加速。

## 录得的问题

v0.6.97日志中，帧1403仍有道路和轮速；帧1405的预测指令剩余时间变成负数，帧1407模型以`ROAD SUPPORT EXPIRED`清空支持。诊断保存的年龄约0.675秒、盲行约4.07cm、误差约4.40cm，说明时间门槛在物理距离门槛之前淘汰了历史几何。后来持续执行了多轮短促寻路，但当前边界观测也没有恢复。

用户STOP后抓取的原图中，白边左侧绿色、右侧灰路面。原算法已经判断内侧在右边；约10.4cm的可见边界经过曲率拟合，再向内偏移15cm时，中线缩短到原来的最低长度以下，整条测量被丢掉。不是一定要同时看到左右两条白边才允许推断道路。

## 当前中线契约

- 当前运行的`road_search.finish_priority=true`启用`LocalRoadModel.persistent_history`。持续保留几何、原始观测时间、每点质量及增长的误差；运动补偿改变坐标，不刷新“看见过”的时间，不伪装为当前观测。
- 不按时间、盲行距离或误差阈值删除主中线。明确绿色反证降低信心并标记，等待新的独立连续观测纠正；不会先清空模型。低质量或闪现的新候选不能覆盖旧预测；一致的新候选经现有多帧确认后，可以在运动中修正旧预测。
- 旧预测和短白边方向推断使用明确的低速恢复档，逻辑轮速峰值60，左右轮比例由中线方向决定。置信度、短视距和包络比例不再反复相乘而得到零输出。恢复状态保留真实误差和包络未验证标志，不宣称已经合规。
- **电机指令的租约不是中线寿命。** 每次最多0.25秒，需要及时的新控制帧继续发布；独立通信/失联保护仍有效。过时的摄像头处理不能靠保留模型持续驱动电机。
- 没有造出中线末端以外的弯道。已存曲线全部移动到车后时仍保存在模型中，但前方没有追踪点，交给主动寻路。明确STOP、完赛和硬件故障仍拥有最终停止权限。
- 保守模式保留旧策略，启动准备仍必须有当前可见道路，不借用历史满足启动确认。

## 短边界的模型层级

常规边界拟合优先。曲率拟合或半路宽偏移失败时，只对已通过原绿色/灰色内外侧证据的短片段，尝试较低阶的直线模型：灰路面朝向证据至少0.8，残差受原观测误差与采样网格约束，不放宽颜色判断；端点最多包含半个采样格的像素面积。它只是从同一可见边界推出方向，不能外推一个看不见的弯道。

若同一画面已有可用常规边界，优先常规边界，避免新短片段否决正常道路。新模型标记`partial_boundary_inference=true`，保持低速恢复并携带短电机租约，即使道路状态为OBSERVED也不会丢掉租约。

## 速度参数

基础档120→135、稳定道路档140→155、加速斜坡320→400 PWM/秒；高置信直路增益保持2.0。原PWM200和0.30m/s上限继续有效，这些数值是指令参数，不表示实际车速提高相同比例。横道及完赛任务继续统一仲裁输出。
