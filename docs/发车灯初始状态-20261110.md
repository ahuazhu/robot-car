# 发车灯准备时灯态

版本：Maix 0.6.84 / ESP32 0.4.16-initial-lamp-state。

目标圈数后增加“准备时灯态”：每次新打开页面默认 OFF，可在 ARM 前选择 ON。模式和圈数、灯面框随同一次 ARM 提交，并在按下时立即固定；准备中、等灯中和本轮行驶期间不可改，STOP 或完赛停车后解除。

- OFF：准备时灯灭；ARM 后记录灭灯参考，裁判亮灯并稳定，再次熄灯后确认出发。
- ON：用户确认准备时灯已亮；ARM 后建立稳定亮灯参考，随后熄灯确认出发。此选择声明现场起始灯态，并不代表系统能从一张图片自动证明灯一定发光。

两种模式均保留亮灯基准 4 帧/300ms、熄灯至少 3 帧/400ms、背景曝光补偿与变暗像素检查。模式只用于本轮，不写入 ESP NVS；出发许可确认后继续锁存，ESP 后续离线不阻止行驶，STOP/完赛仍清除。

接口在 `POST /control` 的 `action=start` 请求顶层增加严格枚举 `initial_lamp_state: OFF|ON`，缺省 OFF。准备请求捕获该值，经 session 传递给 StartSignal 和 ESP ARM。ESP 回报本轮模式；重复同 session ARM 只能保持原模式。旧固件缺字段只允许默认 OFF，显式 ON 必须有匹配回执。

页面脚本回归通过，覆盖默认 OFF、原子提交、ARM 立即锁定、失败重试、刷新恢复、STOP/完赛解除及迟到响应。模式、会话与实际 ESP HTTP/检测核心回归覆盖两种时序、无效输入、旧固件兼容、同 session 改模式拒绝、ON 回执不匹配、取消与断帧、跳过等灯不授许可。全量主机检查运行 832 项：809 通过、23 项可选本机原生内核测试因未装载本机库跳过；设备端原生内核另行核验。

Maix 包和 ESP 固件已构建，ESP Flash 1,713,749 字节、全局 RAM 132,788 字节。此次仍未进行新固件实物亮灭完整周期和赛道发车验证。2026-11-10 已部署 Maix 0.6.84 与 ESP32 0.4.16-initial-lamp-state，运行代码 `d6a005655e76e65be9b3c4a9644f03f1028733ec`。ESP app0 独立校验通过，启动区、分区表、NVS 与 OTA 元数据前缀逐字节一致；六组板上模型数值自检逐值一致、相机持续更新。Maix 38 项代码资源、9 项原生后端核对通过；三项现场配置保持不变。域名入口、ESP 通信和 UNO 零速回执正常；检查时未 ARM、出发许可 false、默认初始灯态 OFF。没有通过工具启动小车。

准备时灯态仅随本页 ARM 提交；Maix 屏幕上的普通 ARM 缺省仍使用 OFF。
