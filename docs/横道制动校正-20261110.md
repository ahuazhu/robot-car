# v0.6.89：把首次刹停点移入目标窗口

v0.6.88首次正向停车实测19cm，模型估计18.25±2.25cm，上界20.5cm，因此停留没有被接受为合法礼让。重新START后另一事件在模型约9.06cm处停满3.30秒并通过，不能作为首次停车的成功验收。本版本校正首次停车的制动预测，不放宽20cm界限，也不增加停车后的细调。

## 根因与参数依据

原配置把0.08m/s²同时用于平顺接近的速度规划和零输出后的物理制动。该值来自历史样本中最低平均减速度的一半以下，仍标记为待现场验证。现在接近速度已改为整车净距缩短速率，0.08的零速制动假设仍导致提前刹停。

新版本保留接近规划0.08m/s²，零输出制动改为0.20m/s²，命令延迟仍取0.35秒。例如首次停车帧927的净距19.899cm、接近速度0.137804m/s，原预测滑行16.692cm；新预测为9.571cm。因此该帧不再请求最终刹停，正常接近到15cm窗口后再停车。

校正没有把两次画面距离之差直接当作精确滑行：帧926已输出零，模型净距22.785±2.284cm；停稳后18.25±2.25cm，按两个误差范围相减得到约9.07cm的行程上界。采用比该帧接近速度更大的已见场景平移速度0.157803m/s，新模型加0.35秒延迟预测约11.75cm，仍保留约2.68cm余量。历史采样的速度下降数据作为补充，未将单次平均减速度视为所有路况下的严格保证。该物理模型仍需下一轮正向重复实测确认。

## 实现边界

`CrosswalkPolicy.approach_deceleration_m_s2`单独描述平顺接近；省略时继承既有制动值，兼容旧配置，并禁止规划减速度大于零速制动能力。接近限速器与SHADOW观察器使用此规划值，保持原来的速度包络；最终刹停预测使用物理制动值。运行配置只调整这两个制动字段及其来源说明，相机标定、车身尺寸、巡线速度、发车配对和看门狗均保持。

合法停位后保持零输出，不因估计波动再挪车；位置误差跨越20cm时仍不能计为完成礼让。红灯、零速回执、实际停稳与3.2秒连续停留的要求不变。横道任务状态及合法停位证据的切换会立即写入既有CONTROL日志，避免0.5秒定期日志遗漏实际刹停切换帧；未行驶时不增加横道变化日志。
