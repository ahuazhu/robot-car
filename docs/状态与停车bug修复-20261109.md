- UNO READY：直接启动和正式信号启动统一要求工作进程存活、无通信错误、ACK不超过1.5秒、UNO未ARM且输出零、故障码为零。急停故障仍可被STOP/STATUS正常读出，但不能使界面误报可启动；ARM的原有硬校验保留。页面显示具体阻止原因。

- 横道一次刹停：删除刹停后因估计停远而自动重新接近的分支，避免零速与慢挪反复切换。保留正常接近时必要的距离制动包络，不承诺所有速度下都能恰好停在10–15cm。

- 8131独立试验：正式Maix ARM期间，按钮、HTTP及串口worker都拒绝试验/修改范围。拒绝不退出采集循环；排队请求遇到正式ARM、失联、配置变化即取消，不延迟触发。最终跨接口竞态仍由ESP32固件已有互斥保护。
- 手动框试验：独立手动检测不再等待无关的模型自检；自动模式仍须自检通过。保存范围期间等待配置确认，收到新鲜M状态也可确认丢失的ROI OK回执。
