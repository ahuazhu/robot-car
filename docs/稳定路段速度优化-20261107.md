# 稳定路段速度优化 2026年11月7日

当前已部署基线v0.6.75先独立提交并推送到experiment/speed-200，提交8f52b03032226ed5fff2afa103594753c75fa062。本次后续优化源码版本为v0.6.76。

## 为什么道路稳定仍然慢

旧控制器的基础油门使用整条保留道路的最低质量；远处或后方历史尾段衰减也会影响当前新鲜的道路目标。所检查的一份实车日志有285条非横道制动、当前道路已接受且观测分数不低于0.65的样本，其中200条全段最低分仍低于0.65。这描述质量来源差异，并不等于所有这些样本都可提速。

此外，提速用的0.4秒连续确认绑定了目标必须正好处于LOOKAHEAD、且车身范围可检查等条件。道路观测仍稳定时，短暂缺少合适前瞻距离或可检查像素，会清空这段确认；恢复后又回基础档。

## 具体改动

道路模型额外输出与控制路径逐点对应的质量分，保留整条道路的最低分用于原有几何、历史与预测判断。只在当前观测、目标本帧可见、测速有效、车身有可检查且为正的余量、没有路径切换且弯曲程度温和时，基础油门取即将使用的前向范围最低分。范围覆盖前瞻点、车身前端及道路宽度对应的滚动检查长度；不是只取目标点的高分。近处或将经过处的旧/弱质量不能被远处高分覆盖。缺失、形状不符、非有限或与全段最低分矛盾的质量数组回退到旧行为。

连续道路观测时间独立维护，仍需0.4秒才能进入现有提速档。短/远支持或车身不可检查的当前命令依然禁止提速，但不会清空其它可靠道路观测积累。弱/丢失/待切换道路、重新采用的新道路、过期处理和超过0.35秒的图像间隔重新确认。测速失效的当前命令不能提速，也不能启用局部质量的基础油门修正。

曲率减速、强弯基础油门、车身碰线检查、横道制动与3.2秒礼让、首次白线30秒规则、末圈40cm停车、预测5cm/0.6秒限制和电机看门狗均保留。巡航参数120/140/163、峰值补偿37及最终PWM上限200不变。

遥测speed_plan增加global_confidence、control_confidence、control_quality_source和forward_confidence，可区分整段历史质量、实际指令质量与前向范围质量。逐点质量只在顶层path_confidence输出，避免在road_model中重复传输。

这些检查证明控制行为与保护条件，不代表实际圈速已经提高。没有扩大电机上限，也没有把PWM当作实测车速。原始日志中另有21/285条当前观测样本的帧周期达到300ms；本次未放宽看门狗或过时图像门槛，计算长帧仍可能引起减速或暂停。
