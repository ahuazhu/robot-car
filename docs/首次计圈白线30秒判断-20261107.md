# 首次计圈白线30秒判断 2026年11月7日

已部署Maix v0.6.75。起步时无法保证相机能看到起终点白线，旧实现始终忽略首次白线，会把第一圈返程误作出发，少计一圈。

新规则仅判断每轮首次可靠识别的计圈白线：连续有效识别起点距实际发车不超过30秒（含第30秒），本次越线忽略；超过30秒，则首次实测越线计为第1圈。后续独立越线正常加圈，不受这30秒窗口限制；仅时间超过30秒、没有白线或没有有效越线测量，不增加圈数。

ARM等灯不会启动窗口；机上真正进入行驶任务后才建立开始时刻。计时包含发车后的停车等待。为防三帧确认跨过30秒边界，检测器保留本次连续观测起点，确认后交给计圈器。首次判定一旦建立不会因稍晚跨线而翻转；发车前已有的观测时间裁剪到本轮发车时刻。未确认闪光不会锁定首次白线的判定。

整车离线与去重、条纹几何过滤、地面运动验证仍有效。达到现场设定目标圈数后正常巡线40cm直接停车；保留v0.6.74的严格JSON布尔状态修复。STOP后再次启动会清空旧圈数和时间窗口，未完成一轮不能中途更改目标圈数。

控制台已更新首次白线说明，并通过initial_line_ignore_s、first_line_seen_after_start_s和first_line_ignored显示相应遥测。尚未看到首次白线时，first_line_ignored为null；此前恒为true的departure_not_counted改为该实际判定。
